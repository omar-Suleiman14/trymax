Or build it yourself

Max pins Node.js 22 and uses Electron's built-in SQLite, so there is no native module to compile. The same three commands produce the installer for whichever platform you run them on.

git clone https://github.com/omar-Suleiman14/max
cd max
npm install && npm run setup:runtime
npm start        # run it
npm run make     # build the installer
