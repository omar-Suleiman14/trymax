Download Max

Get Max for desktop: an offline workspace for notes, databases, forms and workflows. Available for Windows, macOS and Linux. No account needed.

Windows and Linux builds are x64; the macOS build requires Apple silicon. Intel Macs and mobile devices are not supported by these installers.

Windows 10 and 11, x64

Installs for the current user and keeps itself updated from the release feed.

View release
macOS, Apple silicon

Open the DMG and drag Max into Applications. The build is not notarized. Follow the release instructions if macOS blocks the first launch.

View release
Linux — Debian and Ubuntu, amd64

Install with sudo apt install ./max-shop-os_<version>_amd64.deb.

View release
Linux — Flatpak, x86_64 bundle

Install with flatpak install --user ./com.maxshop.Max_stable_x86_64.flatpak.

Or build it yourself

With Node.js 22 installed, run these commands to start Max or build an installer for your system.

git clone https://github.com/omar-Suleiman14/max
cd max
npm install && npm run setup:runtime
npm start        # run it
npm run make     # build the installer
